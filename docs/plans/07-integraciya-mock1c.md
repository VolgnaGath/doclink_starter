# Этап 7 — интеграция mock1c

План принят к реализации 04.11.2026. Основание: ТЗ Ф1, §4.5, этап 7.

1. Протокол: неизменяемые внешние UUID документа/клиента, UTC регистрации,
   PDF/DOCX/TXT + JSON sidecar; дата регистрации не подменяет дату карточки.
2. Заглушка: каталог с фильтром Дата gt, выдача файлов, постоянный журнал
   создания/отмены связей с дедупликацией события (SQLite в volume).
3. PostgreSQL 0011: состояние опроса, входящие записи, transactional outbox,
   попытки обмена. Клиенты namespace=mock1c, gold и корпус не участвуют.
4. Worker: периодический опрос даже при занятой очереди; повторная выдача
   безопасна, записи каталога сохраняются до продвижения отметки; файл и pipeline
   регистрируются атомарно, изменённый внешний ID даёт конфликт.
5. Подтверждение/ручная связь и отмена атомарно создают события. Доставка через
   jobs с прежним event_id, порядком create→remove, ограниченными повторами.
   Отсутствие внешней привязки одной из сторон — видимая блокировка доставки.
6. Интерфейс состояния, повтор ошибок, Makefile/CLI, описание протокола.
7. Проверки PostgreSQL/HTTP, конкурентность/рестарт/таймаут после приёма,
   живая сквозная приёмка, lint/test/verify/migrations и отчёт.

Закрытие: документ inbox автоматически обрабатывается, подтверждение и отмена
доставляются, повторы и рестарт не создают дублей. Измерения моделей — только
реальные ответы или точный кэш с происхождением. Платный допуск не меняется.
