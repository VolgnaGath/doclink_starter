## Реализовано

- Методика `docs/EFFECT.md`: AS-IS=420 с/документ, N=1640, 191,333… ч/месяц.
  Это исходные допущения черновика §1.3, не подтверждённый хронометраж.
- Чистые Decimal-формулы/валидация, четыре полных времени исходов, отдельные
  общие операции, ставка, переменные/постоянные расходы, подготовка 60 договоров,
  разовое внедрение; часы, трудовые затраты, чистый эффект, N*, окупаемость.
  Неизвестное — null, отрицательный эффект сохраняется, c≤0 не даёт конечного N*.
- Read-only адаптер замороженного прогона, unique llm_call IDs с коррекциями,
  общая карточка/выбранная модель, test-входящие/договоры/прочие вычисления отдельно.
  Полные сессии с исходами/actions и исключениями, без суммы накопительных действий.
- Защищённая `/effect`, источники каждого заполненного входа, облако/сервер,
  расчётное GPU-время Qwen при явно заданных скоростях. Qwen подписан
  «открытые веса, облачное размещение». Задержка облачного API не считается временем GPU.
- JSON/Markdown одного снимка, formula_version, дата, источники, полное происхождение,
  calculation_hash и offline replay. Новые замеры создают новый снимок, не dataset.
- README, схема 36 таблиц из metadata, приложения Г/Ж, скриншоты и SHA-256-манифест.
  Повторяемые команды — в Makefile. Схема и REST не потребовали изменений.
