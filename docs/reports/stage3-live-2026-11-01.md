## Цитаты

Для актуальных 56 извлечений: модель предоставила **160 непустых цитат**, из них **145
найдены** проверкой текста. Ещё **109 оснований отсутствуют у заполненных полей**.
Поэтому полное `evidence_ok` — **0/56**, при `valid=true` у всех 56 результатов.
Отсутствие цитаты для неизвестного поля не считается выдуманной цитатой; отсутствие
основания для заполненного поля остаётся неподтверждённым. Проверки не ослаблялись.
Наличие цитаты в тексте само по себе не является оценкой правильности извлечённого поля.
