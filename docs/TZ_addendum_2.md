# Дополнение № 2: отложенный тестовый набор

Согласовано пользователем 04.11.2026. Исходные инструкция и генераторы сохранены
в `corpus_history/addendum_2/`, архив — `addendum_2-original.zip` рядом.

1. Отдельный корпус `synth_holdout`: 30 основных сделок, 221 документ,
   136 входящих, 85 договоров (48 помех), 146 эталонных связей только к договору.
   Генератор прежний, seed 20261104, ID с префиксом `hold_`.
2. Все документы имеют `split=test`. Tune не расширяется. Отдельная версия
   корпуса сохраняет прежние данные и метрики неизменными.
3. До обработки фиксируются прежние веса, пороги каждого варианта, модели,
   промпт и эмбеддер. Повторного подбора и выбора модели на holdout нет.
4. Матрица: три combined-модели, общие rules/semantic, прежние абляции.
   У no_llm ранее нет допустимых порогов: сохраняется
   `NO_FEASIBLE_CONFIGURATION`, пороги для него не придумываются.
5. Первый независимый holdout-прогон имеет `reused_test=false`; прежний
   просмотренный test сохраняет `true`. Результаты показываются отдельно:
   прежний test N=119 и новый holdout N=136; суммарно 255 входящих,
   но это не единый чистый тест N=255.
6. В описание работы бухгалтера входят только фактические сессии БД с
   длительностью и происхождением; снимок обновляется из БД, число 30
   не подставляется вместо фактического количества.
