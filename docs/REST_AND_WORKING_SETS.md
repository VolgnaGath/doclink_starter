## REST

Авторизация — подписанная cookie session от `/login`. API возвращает JSON и 401
без перенаправления. Ошибки: code/message/details, валидация 422, конфликт 409,
неизвестный ресурс 404; детали валидации не отражают исходное значение ввода.
Все следующие пути начинаются с `/api/v1`:

| Операция | Поведение |
|---|---|
| GET/POST `/clients` | Рабочие клиенты; список по умолчанию исключает корпус |
| POST `/documents` | Multipart client_id, files[], is_anonymized=false; 201, отдельный результат каждого файла |
| GET `/documents`, GET `/documents/{id}` | Фильтры/пагинация, карточка, текст, все извлечения, исход, действия/сессии/этапы/связи |
| POST `/documents/{id}/process` | 202; mode=failed/search/extract, model_id только при extract |
| PATCH `/documents/{id}/card` | Ручные значения/сброс через общий CardPatch |
| POST `/documents/{id}/review-sessions` | Отдельная серверная сессия проверки, 201 |
| POST `/documents/{id}/review` | Решения, ручной выбор, завершение/без связей, повторное открытие, отмена |
| POST `/suggestions/{id}/review` | Решение для UUID кандидата |
| GET `/suggestions` | Исходы документов, включая пустые review/none/error; последние, history=true — история |
| GET `/links` | Фильтры по документу/клиенту/типу/происхождению; удалённые при include_removed=true |
| GET `/corpus`, POST `/corpus/import` | Версии и транзакционный импорт ZIP существующим импортёром |
| POST/GET `/working-sets`, GET `/working-sets/{id}` | Изолированный набор, список и происхождение копий |

Пагинация: limit 1–100 (50 по умолчанию), offset ≥ 0; items/total/limit/offset.
Документы, извлечения, исходы, кандидаты, сессии, действия, связи и версии — UUID.
Решение/правка требуют session_id, version, idempotency_key. Повторы/конфликты,
проверка цели/актуальности и атомарная запись — те же сервисы, что и в браузере.
Сессии с длительностью возвращаются отдельно от накопительных длительностей действий.
DTO исключают gold, deal_id, anon_maps, пути хранения, внутренние снимки/настройки
доступа. Filename — basename. Корпус доступен для чтения, изменения/обработка/решения
над оригиналами отвергаются и в API, и в вебе. Исход не меняется при подтверждении.

## Копии и происхождение

WorkingSetCreate: name, corpus_version_id, document_ids выбранных входящих,
необязательные result_ids исходов выбранного метода и idempotency_key.
Без result_ids выбирается последний исход оперативного метода/модели.
Одинаковый запрос возвращает прежний набор, иной запрос с тем же ключом — 409;
весь набор создаётся атомарно, конкурентные запросы сериализованы.

Добавляются все договоры клиентов выбранной версии, включая будущие; дата
фильтруется уже поиском. Неизвестные карточки добавляются как потенциальные договоры.
Отбора по gold/split/сделке нет. Каждый набор получает отдельные рабочие пространства
клиентов, версии не смешиваются. У копий отсутствуют gold/deal_id/split/corpus_doc_id/
corpus_version_id, in_scope=false; источник сохранён в working_sets/working_copies.
Текст/blob переиспользуются, имена копий нейтральные. Связи/действия из корпуса
не копируются, решения за бухгалтера не создаются. Поиск выполняется заново.

Проверяются снимок, фактический запрос, ключ исходного вызова, текст, обезличенность
и клиентский контекст. Сохраняются source_extraction_id/llm_call_id/input_hash/cache_hit.
Только доверенная неизменённая обезличенная копия наследует исходную область кэша
клиента; изменение текста/контекста отключает её. Обычные загрузки её не наследуют.
Сохранённые ошибки переносятся и защищены от улучшения повтором. Векторы — только
по точным ключам BGE-M3 и хешам текста. Исходные данные/результаты не изменяются.

В исходе и контексте сессии есть working_set_id/source_document_id/source_result_id/
initial_inputs. Источник — явная привязка для будущего experiment_runs; фиктивных
прогонов нет. Актуальность исходного результата сверяется перед копированием.
Ревизия учитывает карточки, текст, извлечения, переопределения и историю правок
рабочего клиента. Сброс значения не стирает факт ручной работы. Явный повтор также
снимает initial_inputs. Сохранённый контекст сессии неизменен: замеры после правок
и повторов не приписываются исходному результату автоматически.

## ZIP

Корни real/synth/synth_extra напрямую либо под corpus/. Лимиты: архив 100 МиБ,
распакованные данные 256 МиБ, 10000 записей, отдельный файл max_file_bytes
(25 МиБ по умолчанию). Отвергаются абсолютные пути, `..`, обратные слеши,
симлинки, шифрование и дубли. Потоковая распаковка ограничивает фактические байты,
временный каталог удаляется. Дальше штатный импортёр проверяет CSV/manifest/ссылки,
сохраняет эталон только в оценочном контуре и повторно использует идентичную версию.
