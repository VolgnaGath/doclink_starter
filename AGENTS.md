# AGENTS.md — DocLink

Сервис установления связей между документами договорного процесса (договор, допсоглашение, счёт, акт, УПД).
Прототип для магистерской диссертации и стенд для воспроизводимого эксперимента.

## Источники истины

1. `docs/TZ.md` — ТЗ, база. Меняется только отдельным решением и отдельным коммитом с префиксом `TZ:`.
2. `docs/DECISIONS.md` — датированные уточнения и детали реализации. Не отменяет ТЗ; при расхождении действует ТЗ,
   а расхождение фиксируется в `CONTEXT.md` как открытый вопрос.
3. `CONTEXT.md` — состояние на текущую сессию: что сделано, инварианты, открытые вопросы, следующий шаг.
4. `IMPLEMENTATION_STATUS.md` — этапы 0–7: сделано / реально проверено / не запускалось и почему.

Перед началом работы прочитай `CONTEXT.md`. Код и тесты — источник деталей реализации.

## Рабочий процесс

- Любое изменение сразу коммитим и пушим в `origin/main`. Ветки и pull request не используем, пока нет CI.
- Коммиты небольшие, по смыслу; сообщение — что изменено и зачем.
- В том же коммите обновляй `CONTEXT.md`, если изменились состояние, инварианты или следующий шаг.
- При завершении этапа обнови `IMPLEMENTATION_STATUS.md` (сделано / реально проверено / не запускалось).
- Перед коммитом: `make lint` и `make test`. Если проверка не запускалась — зафиксируй причину в `CONTEXT.md`.
- Не меняй файлы в `reference/` и не импортируй их из движка связывания.

## Makefile — обязателен

- Любая повторяемая команда (запуск, миграции, импорт корпуса, тесты, линт, платный smoke) живёт в `Makefile`.
- Актуальный список целей — `make help`. Не дублируй его в `AGENTS.md` и `README.md`.
- Добавляешь команду — добавь цель и описание для `make help` в том же коммите.
- `make test` не делает платных вызовов. Живые вызовы — только `make smoke-paid` при `PAID_CALLS_ENABLED=true`
  и положительном `BUDGET_RUB`.

## Незыблемые правила

1. **Честность эксперимента.** Метрики считаются только по реальным вызовам моделей. Никаких заглушек,
   возвращающих правдоподобные числа. Ошибки обработки учитываются по `docs/DECISIONS.md`.
2. **Без утечки из будущего.** Кандидат — договор того же клиента с датой не позже даты документа, без допуска.
   Пороги подбираются только на `split=tune`, метрики считаются только на `split=test`.
3. **Эталон изолирован.** Эталонные связи, `deal_id`, `split`, `hard_types` и имена папок не попадают во вход движка,
   промпт и векторы. Модуль оценки не импортируется движком связывания.
4. **Всё логируется.** Каждый вызов модели — в `llm_calls` (токены, задержка, стоимость, сырой ответ, `truncated`),
   каждое решение — в `link_suggestions` с признаками, каждое действие бухгалтера — в `review_actions` с длительностью.
5. **Секреты только в `.env`.** Не логировать заголовки авторизации, не писать ключи в БД и в репозиторий.
6. **Персональные данные.** Перед внешним API текст обезличивается, если у документа нет `is_anonymized=true`.
   Таблица `anon_maps` никуда не выгружается.
7. **Платные вызовы под замком.** По умолчанию провайдер `mock`; живые вызовы — только при `PAID_CALLS_ENABLED=true`
   и положительном `BUDGET_RUB`.
8. **Сбой ≠ отказ.** Таймаут или невалидный ответ после ограниченных повторов — статус «Ошибка обработки»,
   а не «нет кандидата». Неизвестная стоимость — `null`, не `0`. Ошибки не кэшируются как успех.
9. **Фиксация протокола.** Перед прогоном test конфигурация (веса, пороги, промпт, модель) замораживается по хешу.
   После просмотра test любое изменение метода — новый прогон с пометкой `reused_test`.
10. **Обрезка текста явная.** Если текст обрезан (6000 + 2500 символов), это пишется в `llm_calls.truncated`.
11. **Все связи подтверждает бухгалтер.** В `links` только `confirmed`/`manual` со ссылкой на `review_actions`.
12. **Размещение моделей.** Qwen в Yandex AI Studio — `placement=open-weights-cloud`, в отчётах подписывать
    «открытые веса, облачное размещение». Время локального запуска только оценивается по формуле из ТЗ, не измеряется.

## Конвенции кода

- Python 3.12, типы везде, SQLAlchemy 2, Pydantic v2, FastAPI, Jinja2 + HTMX без SPA.
- Функции метода — чистые, без БД, в `app/services/linking/*`: их легко тестировать и сравнивать с эталоном.
- Интерфейс на русском. Даты `ДД.ММ.ГГГГ`, суммы с пробелами-разделителями.
- Не добавлять зависимости без необходимости; фиксировать в `pyproject.toml` и lock-файле.
- Очередь — таблица `jobs` с `FOR UPDATE SKIP LOCKED`; Redis не используется.

## Карта репозитория

```
app/            # FastAPI, worker, сервисы, веб-интерфейс (этап 0+)
mock1c/         # заглушка OData и inbox
prompts/        # версии инструкций и JSON-схемы
corpus/         # корпус оценки: real/, synth/, documents.csv, links.csv
reference/      # эталонные скрипты, только чтение
docs/           # TZ.md, DECISIONS.md
migrations/  tests/  Dockerfile  docker-compose.yml  pyproject.toml
```
