## Проверка этапа 1

- `make lock` генерирует `uv.lock` закреплённой версией uv; `docker compose config -q` проходит.
- `make test`: 13 passed; есть одно предупреждение Starlette о будущей замене httpx в TestClient.
- `make lint`: `ruff check` и `ruff format --check` проходят.
- После `make up`: `api`, `db`, `mock1c` здоровы, worker запущен и пишет heartbeat.
- `/health`: при доступной БД `{"status":"ok","db":true,"version":"0.1.0"}`; при остановленной БД —
  HTTP 200 `degraded`, контейнер api остаётся здоровым; после запуска БД состояние восстанавливается.
- Вход: неверный пароль — 401; верный — 303 и cookie-сессия; `/` — 200; logout — 303, после него `/`
  снова перенаправляет на вход. Внешний `next` проверен тестами.
- `make migrate` создаёт расширение `vector` 0.8.7; результат проверен через `psql \dx` после чистого запуска.
- mock1c возвращает `{"status":"ok"}` и `{"value":[]}`; worker завершается по SIGTERM с кодом 0.
- `docker compose down -v && make up && make migrate` выполнено успешно. Платных вызовов не было.
