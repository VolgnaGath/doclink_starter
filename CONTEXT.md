## Инварианты

- Gold/split/deal_id/hard_types/пути/ответы других моделей не входят во вход модели или кэш.
- Кандидат — договор того же клиента, дата не позже документа; карточка не заполняется из gold.
- Связи только после бухгалтера. Пороги tune, метрики test. Ошибка не равна «нет кандидата».
- Секреты — `.env`, anon_maps не выгружается, reference/ не меняется и не импортируется.
- Бюджет общий по БД с учётом резервов; стоимость физического вызова — по историческому тарифу.

## Открытые вопросы и следующий шаг

- Перед генерациями реализовать независимые лимиты 500 ₽ на Yandex и GigaChat,
  определить учёт пакетных расходов GigaChat; не подставлять цену 0 из наличия пакета.
- Yandex URI/тарифы подтверждены скриншотами пользователя, права ключа ещё не проверены.
- Сертификат root истекает 2032-02-27; sub — 2027-03-06, sub2024 — 2029-07-19. Для новой машины
  восстановить игнорируемые certs/ файлы через gigachat-ca или gigachat-ca-install и пересобрать образ.
- Полная приёмка: live smoke → tune → freeze → корпус на трёх моделях → продолжение/расходы.
  До этого этап 3 остаётся «в работе». Метаданные аккаунта проверяются отдельными целями Makefile,
  не создают фиктивные llm_calls; платная генерация только через smoke-paid.
- Пользователь выбрал редакцию синтетики с сохранением 156 связей; негативные сценарии — отдельно.
  Для приёмки использовать только v2, не смешивать документы двух corpus_versions.
  В real частично нет gold ИНН/суммы/предмета.
- CSRF: локальный прототип SameSite=Lax без токена; пересмотреть при выносе наружу.
